# 板材套裁系统

板式家具厂的开料优化与余料复用管理：把每张板切得尽量满，边角料登记进台账给后面的单子用，改单只动没开料的部分，月末出利用率报表。

## 功能

- **板材台账**：按规格（长×宽×厚）和材质建档。
- **订单管理**：每个订单拆成开料需求（部件名、尺寸、数量）。
- **套裁方案**：一键生成排版方案——要开几张整板、吃哪几块余料、每件部件落在哪张板的哪个位置（SVG 排版图）、剩哪些边角料；确认开料后边角料自动登记进余料台账。
- **余料复用台账**：边角料按规格和存放位置登记；新订单开料**先吃余料、再开整板**，选料规则：已打开的余料 → 库存余料中"能放下且面积最小"的（面积相同先入先用）→ 已打开的整板 → 才新开整板。
- **变更单**：只能追加部件、或减少**还没开料**的数量（不能减到已开料数以下）；已开料的部件和已执行的方案一律不许动。变更后自动按最新需求重算套裁方案（新版本草稿）和耗板数，前后对比留痕。
- **月末统计**：板材利用率（按整张数 / 按面积两个口径）＋ 余料复用台账月结 ＋ 投入产出对账平衡式。

## 技术栈与结构

前端 Vue 3 + Vite + TypeScript；后端 Fastify + better-sqlite3，前后端分层。
**所有长度按毫米、面积按平方毫米的整数存储和计算，百分比用万分比整数，全程无浮点。**

```
server/                  后端
  src/core/              错误、时间等公共件
  src/db/                建库建表、种子数据（5 种板材、10 个订单(2 个改过单)、一批边角料）
  src/modules/
    boards/              板材台账
    orders/              订单与开料需求
    nesting/             套裁方案（packer.ts 排版引擎 + service.ts 方案生成/开料）
    remnants/            余料匹配（matcher.ts 纯函数）与余料台账
    changes/             变更单与改单重算
    stats/               利用率统计与余料月结
  test/                  Vitest（余料匹配、改单重算、利用率、排版引擎、开料全流程）
web/                     前端（六个页面：订单、订单详情、板材、余料、变更、统计）
```

## 启动

要求 Node.js ≥ 18（建议 20/22）。

```bash
npm install          # 一次装好 server 和 web（npm workspaces）

# 终端 1：后端 http://localhost:3001
npm run dev:server   # 首次启动自动建库（server/data/app.db）并写入演示数据

# 终端 2：前端 http://localhost:5173
npm run dev:web
```

浏览器打开 **http://localhost:5173**。

```bash
npm test             # 后端 Vitest（28 个用例）
npm run build        # 前端类型检查 + 构建
```

想重置演示数据：删掉 `server/data/app.db` 再重启后端即可（或 `cd server && npm run seed -- --reset`）。

## 验收路径（对应界面操作）

1. **开一单看算板**：订单管理 → 新建订单 → 进入详情 →「生成套裁方案」→ 看整板张数、每块板的排版图 →「确认开料」→ 余料台账里能看到新登记的边角料。
2. **余料优先**：余料台账有货时再开一单小件 → 生成方案 → 整板 0 张，方案里标注吃了哪块余料（如"余料 #39"）。
3. **改单不动已开料**：找一个已开料的订单 →「发起变更」→ 加两块层板 → 已开料部件的数量/已开料数原封不动，原方案保持"已开料"状态。
4. **耗板数重算**：变更提交后自动生成新版本方案，变更单里能看到整板/余料耗用前后对比；操作留痕时间线同步记录。
5. **月末对账**：月末统计 → 选月份 → 两个口径的利用率、投入产出对账平衡式（✓ 即平）、余料台账月结（期初＋登记－耗用＝期末）。

## 口径定义

- **按整张数利用率** ＝ 整板切出的部件面积 ÷ 新开整板总面积（每张整板切得满不满）。
- **按面积利用率** ＝ 全部部件面积 ÷（新开整板面积 ＋ 耗用余料面积）（含余料复用的综合材料利用）。
- **对账等式**（每块板由排版引擎保证，月度汇总恒等）：
  投入面积（整板＋耗用余料）＝ 部件面积 ＋ 回收余料面积 ＋ 损耗面积。
- **余料登记规则**：切完的空闲矩形中，短边 ≥ 150mm 且面积 ≥ 45,000mm² 的才登记进台账，更小的计入损耗。
- **变更规则**：追加不限；减少只能减未开料的部分（新数量 ≥ 已开料数）；已执行方案与已开料部件不可改。
- 排版引擎为 Guillotine（直通锯路）+ 最佳面积适配，支持锯缝（kerf）和"允许旋转"选项（有木纹方向要求时不要开）。
